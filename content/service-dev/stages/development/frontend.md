## 개념

사용자가 **직접 보고 누르는 화면** 쪽이다. 웹이면 HTML(뼈대)·CSS(모양)·JS(동작)로 만든다.
필요한 데이터는 서버에 요청해 받아 와 그린다. 화면 크기에 맞춰 배치가 바뀌게(반응형) 만들면 PC와 폰을 하나로 대응한다.

## 왜 나왔나

웹은 HTML(구조)·CSS(모양)·JS(동작)로, 앱은 React Native 같은 도구로 만든다. 반응형 웹이면 하나로 PC와 모바일을 모두 대응한다.
