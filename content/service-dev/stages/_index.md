## 개념

서비스가 **기획 → 설계 → 개발 → 소스 관리 → 배포 → 출시 → 유지보수 → 수익화**로 거쳐 가는 순서다.
앞단(기획·설계)은 헛수고를 막고, 뒷단(유지보수·수익화)은 출시가 끝이 아님을 뜻한다. 각 단계에서 무엇을 정하고 무엇을 만드는지가 다르다.

## 왜 나왔나

기획 → 설계 → 개발 → 소스 관리 → 배포 → 출시 → 유지보수 → 수익화로 이어진다.
다 만들고 나서 아무도 안 쓰는 걸 막으려고 앞단(기획)을 먼저 두고,
출시 이후에도 끝나지 않으니 뒷단(유지보수·수익화)을 붙였다.
