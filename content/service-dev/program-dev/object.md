## 개념

클래스라는 설계도로 **메모리에 실제로 만들어 낸 것**이다. 인스턴스라고도 한다.
같은 클래스에서 만들어도 객체마다 자기 데이터를 따로 가진다. "사용자" 클래스에서 철수 객체와 영희 객체가 나온다.

## 왜 나왔나

설계도(클래스)는 하나지만 실제 사람 A, B는 여럿이다. 인스턴스화하면 각자 메모리를 차지하는 실체가 된다.
