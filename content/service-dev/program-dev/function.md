## 개념

**입력을 받아 정해진 일을 하고 결과를 돌려주는** 코드 묶음이다. 가장 작은 재사용 단위다.
같은 일을 여러 곳에서 하면 함수로 만들어 이름을 붙이고 부른다. 그러면 고칠 때 한 곳만 고치면 된다.

## 왜 나왔나

같은 코드를 여러 번 쓰지 않으려고, 수학의 f(x)=ax+b처럼 **이름을 붙여 호출**하게 했다.
