## 개념

CPU가 알아듣는 명령어의 **목록과 형식**이다. "이 비트 패턴은 더하기, 저 패턴은 메모리에서 읽기"처럼 정해 둔 약속이다.
컴파일러는 소스 코드를 이 명령어들로 바꾸고, CPU는 그걸 실행한다. 같은 ISA를 따르면 CPU 제조사가 달라도 같은 프로그램이 돈다.

## 왜 나왔나

소프트웨어와 하드웨어 사이의 약속. 같은 ISA를 따르면 CPU가 바뀌어도 같은 프로그램이 돈다.
