## 개념

한 번 작성하면 **어느 컴퓨터에서든 같게 돌도록** 만든 언어와 실행 환경이다. 소스를 바이트코드로 바꾸고, 각 컴퓨터의 JVM이 그걸 실행한다.
객체 지향, 자동 메모리 관리(GC), 풍부한 라이브러리가 특징이라 서버 개발에 널리 쓰인다.

## 왜 나왔나

(작성 예정 — HANDOFF 5-5 순서상 서비스 개발 다음이다.)

이 과목의 값어치는 **CS 기초와 이어 붙는 데** 있다.
JVM 메모리 구조는 운영체제의 메모리 영역과, GC는 페이지 교체 기법과,
스레드 풀은 프로세스·스레드와 같은 이야기다. (HANDOFF 5-6)
