v3에서 바뀐 점 (한줄평 반영)
  • ▶ 눈으로 보기: 페이지 교체(FIFO·LRU·OPT), CPU 스케줄링(FCFS·SJF·SRTF·RR), 주소 변환(TLB·페이지 테이블·페이지 폴트), 디스크 스케줄링, 캐시와 지역성. 모두 영상처럼 한 단계씩 움직여요. 트리에서 ▶ 표시가 붙은 개념을 누르면 열려요. ← 첨부 영상
  • 모르는 용어 누르기: 보라색 점선 밑줄 용어를 누르면 바로 아래에 설명 카드가 펼쳐져요. 카드 안의 용어도 또 누를 수 있어요(용어 따라가기). 트리에 있는 개념이면 바로 이동하고, “← 돌아가기”로 원래 개념에 돌아와요. ← 심화 탭 한줄평
  • 읽기 편한 설명: 문장마다 줄을 나누고, 핵심 구절에 형광펜을 칠하고, “그래서 / 하지만” 같은 연결어를 색으로 표시했어요. ← 가독성
  • 깊이별 색: 진할수록 큰 개념이에요. 누른 노드가 흰색으로 바뀌지 않고, 펼침/접힘은 ＋/− 로 보여줘요. ← 좌→우 트리 한줄평
  • 위→아래 트리 정리: 곡선 대신 직각 연결선을 쓰고, 글자를 키우고, 튀어나오던 세로 바를 없앴어요. 흐름 화살표는 바로 옆 개념끼리만 그리고, 이유 글씨는 선택했을 때만 보여요. ← 위→아래 한줄평
  • 기초 / 심화로 표기를 바꿨고, 🎧 집중(노이즈 + 뽀모도로)을 추가했어요. 기여 탭은 일단 뺐어요.
